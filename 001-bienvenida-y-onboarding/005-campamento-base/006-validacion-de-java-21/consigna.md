## Objetivo

Comprobar que Java 21 quedó instalado y que es la versión activa en la terminal.

## Consigna

Ejecutá el comando de verificación de Java en tu terminal y respondé la pregunta
del cuestionario.

## Criterios de aceptación

- Haber ejecutado el comando de verificación.
- Responder correctamente la única pregunta.

## Pistas

- El comando de verificación aparece en la página de instalación de Java 21.
- Si la versión no es 21, revisá la versión predeterminada de SDKMAN.
