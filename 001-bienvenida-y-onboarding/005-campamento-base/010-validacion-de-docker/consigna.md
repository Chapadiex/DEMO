## Objetivo

Comprobar que Docker quedó instalado y que puede ejecutar un contenedor.

## Consigna

Ejecutá el comando de verificación de Docker en tu terminal y respondé la
pregunta del cuestionario.

## Criterios de aceptación

- Haber ejecutado el comando de verificación.
- Responder correctamente la única pregunta.

## Pistas

- El comando de verificación aparece en la página de instalación de Docker.
- Si el motor no está iniciado, abrí Docker Desktop o iniciá el servicio.
