## Objetivo

Comprobar que Git quedó instalado y que la terminal reconoce sus comandos.

## Consigna

Ejecutá el comando de verificación de Git en tu terminal y respondé la pregunta
del cuestionario.

## Criterios de aceptación

- Haber ejecutado el comando de verificación.
- Responder correctamente la única pregunta.

## Pistas

- El comando de verificación aparece en la página de instalación de Git y Git
  Bash.
