## Objetivo

Comprobar que Maven quedó instalado y que la terminal reconoce el comando `mvn`.

## Consigna

Ejecutá el comando de verificación de Maven en tu terminal y respondé la
pregunta del cuestionario.

## Criterios de aceptación

- Haber ejecutado el comando de verificación.
- Responder correctamente la única pregunta.

## Pistas

- El comando de verificación aparece en la página de instalación de Maven.
- Revisá también que la salida indique Java 21.
