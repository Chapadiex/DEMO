## Qué vas a instalar

Git es el sistema de control de versiones que vas a usar durante toda la
asignatura. Git Bash es una terminal para Windows que incluye Git y herramientas
de línea de comandos. En macOS y Linux vas a usar la terminal del sistema.

## Antes de empezar

Verificá si Git ya está instalado:

```bash
git --version
```

Si el comando muestra una versión, podés continuar con la validación. Si no se
reconoce, instalalo con las instrucciones de tu sistema operativo.

## Instalación

### Windows

1. Descargá Git for Windows desde https://git-scm.com/downloads.
2. Ejecutá el instalador y mantené las opciones recomendadas. Git Bash se
   instala junto con Git.
3. Abrí Git Bash desde el menú de inicio.

### macOS

Instalá Git con Homebrew:

```bash
brew install git
```

Si no tenés Homebrew, instalalo desde https://brew.sh/ o usá el instalador de
Git para macOS.

### Linux

Usá el gestor de paquetes de tu distribución. En Ubuntu o Debian:

```bash
sudo apt update
sudo apt install git
```

## Verificación

En Git Bash o en la terminal, ejecutá:

```bash
git --version
```

Deberías ver una salida similar a `git version 2.x.x`. Si el comando no se
reconoce, cerrá y volvé a abrir la terminal; si el problema continúa, revisá la
instalación.

## Siguiente paso

Cuando la verificación funcione, resolvé la validación de Git y Git Bash.
